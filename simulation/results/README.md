# Simulation result files

- `*_raw.csv`: one row per estimator, replicate, and condition.
- `*_scores.csv`: coefficient-level truth, estimates, standard errors, and selection scores.
- `*_diagnostics.csv`: convergence, stationarity, objective, and PIP-sampling diagnostics.
- `*_summary.csv`: condition-level means and Monte Carlo standard errors.
- `sim_tuning_*`: tuning fits, grid summaries, and selected settings.
- `sim_objective_validation_*` and `sim_integrated_pip_validation.csv`: algorithmic validation.
- `sim_whitening_*`: whitening and parameter-order sensitivity.
- `sim_empirical_covariance_*`: stylized and resampled-NARPS covariance sensitivity.
- `simulation_tables_generated.tex` and `fig_simulation_*.png`: manuscript-ready outputs.

All final retained diagnostic records are converged.
