# Real-data result files

- `real_data_fits.rds`: proposed intercept and gender-age fits, conditional Laplace covariance, metadata, and contrasts.
- `real_data_estimates.csv`: proposed estimates and PIPs.
- `spm_peb_fits.rds` and `spm_peb_estimates.csv`: SPM-PEB reference fits and summaries.
- `method_comparison.csv` and `covariate_comparison.csv`: proposed-versus-SPM comparisons.
- `task_version_sensitivity.csv` and `task_version_sensitivity_fits.rds`: task-version-adjusted sensitivity analysis.
- `real_A_matrices.csv`: intrinsic connectivity in physical Hz for display and corresponding PIPs.
- `real_fig1_A_annotated.png`: corrected intrinsic-connectivity and PIP figure.
- `dcm_input_audit*`: event, SPM, and DCM input-alignment audit.
- `subject_run_*`, `run_level_*`, `within_subject_*`, and `revision_*`: first-level condition counts, ranks, fit diagnostics, and prior-to-posterior variance changes.

`res2_corrected.rds`, which is an analysis input rather than a result, is stored one level above this folder.
